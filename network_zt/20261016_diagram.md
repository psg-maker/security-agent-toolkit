# day05 경보 판단

## 이상한 줄
- 줄 번호: 2번, 3번
- 이유: 인터넷의 PC(192.0.2.7)가 내부망에 있는 DB의 3306 포트로 직접 접속했고, 방화벽이 이를 허용했다.

## 고친 구성도
```text
INTERNET ──── FW ──┬── DMZ    : WEB (443 open)
                   └── INSIDE : DB  (3306 from WEB only)
```

## 방화벽 규칙 수정
- 인터넷 → WEB의 443 포트: 허용
- 인터넷 → DB의 3306 포트: 차단
- WEB → DB의 3306 포트: 허용
