# 정산 포털 로그 점검 결과 (10/21(수))

## 결론

- 제공된 접속 기록 20건 중 8건이 거부되었으며, seoyeon의 미등록 기기 접속 시도 두 건은 모두 차단되었고 02:13의 허용은 본인 등록 기기에서 발생했다.

## 정정 (3-1 에서 읽은 것 중 바뀐 것 · 바뀌지 않은 것)

- 바뀐 것: 3-1에서는 seoyeon이 미등록 기기로 거부된 뒤 다른 기기로 허용되어 의심스럽다고 판단했다. 새 자료에서 02:13에 사용된 NB-0417이 seoyeon의 등록 기기임을 확인했으므로, 해당 허용을 비정상 접속으로 볼 근거는 약해졌다. 다만 등록 기기라는 사실만으로 실제 사용자가 본인이라고 확정할 수는 없다.
- 바뀌지 않은 것: 미등록 기기 NB-7741에서 02:10과 15:20에 seoyeon 계정으로 두 번 접속을 시도했고 모두 거부되었다. 해당 기기의 소유자와 실제 시도자가 누구인지는 추가 확인이 필요하다.

## 근거

- seoyeon은 02:10에 NB-7741로 접속하다 ‘미등록 기기’로 거부되었고, 02:13에는 등록 기기 NB-0417로 허용되었다. 15:20에는 NB-7741에서 다시 거부되었다.
- junho는 09:41에 NB-0522에서 ‘MFA 안 함’으로 거부된 뒤 09:44에 같은 기기로 허용되었다. 추가 인증 후 재시도했을 가능성이 있으나 인증 완료 기록을 확인해야 한다.
- ‘거부 뒤 허용’ 기준을 10분 또는 30분으로 잡으면 두 건이며, 60분으로 늘리면 jiho의 14:40 허용이 추가되어 세 건이다. 탐지 기준에 따라 목록이 달라지며, 발견된 건을 모두 공격으로 단정할 수 없다.
- 전체 20건 중 거부는 8건(40%)이다. 평소 거부율과 비교할 자료가 없어 이 비율이 높은지는 판단할 수 없다.

```text
미등록 기기 ## 2
퇴사 계정 #### 4
MFA 안 함 # 1
해외 접속 # 1
```

## 권고 (먼저 할 것부터)

1. 조치: seoyeon 본인에게 NB-7741 사용 여부를 확인하고 비밀번호 변경을 안내한다. / 막을 수 있는 위험: 계정 정보 노출을 조기에 발견하고 추가 접속 위험을 줄인다. / 정상 직원에게 생기는 불편: 확인 연락과 비밀번호 변경이 필요하며, 답변이 늦으면 확인이 지연된다.
2. 조치: 퇴사 계정 dami의 비활성화 상태를 확인해 비활성화하고 NB-0333의 기기 등록을 삭제한다. / 막을 수 있는 위험: 퇴사 계정과 남아 있는 기기 등록을 이용한 접근 위험을 줄인다. / 정상 직원에게 생기는 불편: 퇴사가 확정된 계정이므로 정상 직원의 업무 영향은 작다.
3. 조치: ‘거부 뒤 60분 이내 허용’ 목록을 매일 검토한다. / 막을 수 있는 위험: 10분 기준으로 놓치는 사례를 추가로 조사할 수 있다. / 정상 직원에게 생기는 불편: 정상 재시도도 검토 대상이 되어 담당자의 확인 업무와 사용자 문의가 늘어난다.

이 순서는 현재 확인이 필요한 seoyeon 건에 먼저 대응하고, 퇴사가 확인되어 부작용이 작은 조치를 처리한 뒤, 지속적인 탐지 범위를 넓히는 순서이다. 60분 기준 세 건 중 junho와 jiho 두 건은 같은 기기로 재시도한 사례이므로, 모두 차단하면 정상 업무까지 중단할 수 있다. 같은 기기라는 이유만으로 정상이라고 확정하지 않고 관련 기록을 확인한다.
